① 股價資料拉取（yfinance）

後端以 yfinance 抓取台股 OHLCV 日線（代號加 .TW 後綴）。 前端傳入 trading_days，後端多抓 1.5 倍日曆天再截取最後 N 筆交易日，確保非交易日不計入。 展示以隨機遊走模擬收盤價。

# api_server.py /api/stock_chart import yfinance as yf ticker = yf.Ticker(f"{stock_id}.TW") df = ticker.history(start=start_date, end=end_date, interval="1d") # trading_days 模式：多抓 1.5 倍日曆天再截取 if trading_days: start_date = today - timedelta(days=int(trading_days * 1.5)) records = records[-trading_days:] # 截取最後 N 個交易日

② 加權線性回歸（指數衰減）

普通線性回歸對所有資料點等權重，但股價的近期走勢影響力更大。 採用指數衰減權重 w[i] = exp(λ × i)（i=0 最舊，越新越重），讓近期資料主導回歸方向。 調整 λ 可看到回歸線如何隨近期走勢傾斜。

# 加權線性回歸核心（指數衰減） lam = 0.1 weights = [math.exp(lam * i) for i in range(n)] # i=0 最舊 w_sum = sum(weights) x_mean_w = sum(weights[i] * i for i in range(n)) / w_sum y_mean_w = sum(weights[i] * closes[i] for i in range(n)) / w_sum num_w = sum(weights[i] * (i - x_mean_w) * (closes[i] - y_mean_w) for i in range(n)) den_w = sum(weights[i] * (i - x_mean_w) ** 2 for i in range(n)) slope = num_w / den_w intercept = y_mean_w - slope * x_mean_w

③ 短期動能斜率

長期回歸捕捉整體方向，但預測需要「最近幾天的慣性」。 取最近 5 個交易日，用更快的衰減（λ=0.2）做一次獨立加權回歸，得到 short_slope。 調整滑桿，比較短期斜率與長期斜率在不同行情下的差異。

# 短期動能斜率（最近 N 日加權回歸） n5 = 5 # 短期窗口 closes5 = closes[-n5:] w5 = [math.exp(0.2 * i) for i in range(n5)] # 更快的衰減 w5s = sum(w5) x5mw = sum(w5[i] * i for i in range(n5)) / w5s y5mw = sum(w5[i] * closes5[i] for i in range(n5)) / w5s n5d = sum(w5[i] * (i - x5mw)**2 for i in range(n5)) short_slope = sum(w5[i]*(i-x5mw)*(closes5[i]-y5mw) for i in range(n5)) / n5d

④ MA20 均值回歸融合

純動能預測會無限延伸（若漲就一直漲），但股價有均值回歸傾向。 以 MA20（20日移動平均）作為「目標錨點」，每日拉力 = (MA20 − price) / 20。 預測時用指數衰減 exp(-0.18 × i) 融合兩者：初期由動能主導，越後期越被 MA20 吸引。

# 動能 + 均值回歸融合（20 步預測） ma20 = sum(closes[-20:]) / min(20, n) mean_pull_day = (ma20 - last_price) / 20 # 每日 MA20 拉力 price = last_price regression_future = [] for i in range(20): decay = math.exp(-0.18 * i) # 動能隨時間衰退 daily_move = decay * short_slope + (1 - decay) * mean_pull_day price = round(price + daily_move, 2) regression_future.append(price)

⑤ 完整預測合成

整合以上所有算法：歷史段顯示收盤價與加權回歸線，未來段同時顯示「數學預測線」（③短期動能 + ④MA20融合） 與「AI 預測線」（LLM 給出目標漲跌幅後線性插值）。 拖動滑桿模擬 AI 給出的漲跌幅。

# AI 預測線：線性插值到目標價 target_price = last_price * (1 + ai_change_pct / 100) ai_future = [ round(last_price + (target_price - last_price) * (i + 1) / 20, 2) for i in range(20) ] # 數學預測線：動能衰減 + MA20 均值回歸 price = last_price for i in range(20): decay = math.exp(-0.18 * i) daily_move = decay * short_slope + (1 - decay) * mean_pull_day price += daily_move regression_future.append(round(price, 2))
